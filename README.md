# mi-portafolio
Portafolio profesional de una Ingeniera en Sistemas Computacionales. Un espacio para presentar mis proyectos, conocimientos en desarrollo web, bases de datos y análisis de datos, así como mi formación y crecimiento profesional.

Actúa como un desarrollador web senior especializado en React, diseño UI/UX y Tailwind CSS.

Quiero construir un portafolio profesional personal, moderno e interactivo, con una estética gamer rosa, tecnológica y elegante.

**Mi identidad profesional:**
Ingeniera en Sistemas Computacionales | Desarrolladora web Jr | Bases de datos | Análisis de datos.

**Objetivo del sitio:**
Presentar mi perfil profesional, proyectos académicos, conocimientos técnicos, formación y medios de contacto para posibles oportunidades laborales.

**Diseño visual:**
- Estética gamer rosa, moderna y profesional.
- Paleta de colores rosa pastel, fucsia, blanco y tonos complementarios.
- Detalles decorativos pixel art y elementos tecnológicos sutiles.
- Tarjetas con bordes redondeados, sombras suaves y efectos visuales.
- Tipografía moderna y legible.
- Diseño adaptable a computadoras, tabletas y celulares.

**Estructura inicial:**
1. Inicio: presentación principal con mi nombre, título profesional y botón para conocer mis proyectos.
2. Proyectos: tarjetas interactivas para mostrar mis trabajos.
3. Sobre mí: presentación personal con un avatar ilustrado estilo gamer.
4. Habilidades: tecnologías y herramientas que conozco.
5. Experiencia y formación.
6. Certificaciones y cursos.
7. Contacto.

**Navegación e interacciones:**
- Barra de navegación fija.
- Desplazamiento suave entre secciones.
- Animaciones sutiles al aparecer los elementos.
- Efectos hover en botones y tarjetas.
- Botón funcional para cambiar entre modo claro y oscuro.
- Menú adaptable para dispositivos móviles.

**Requisitos técnicos:**
- Utiliza React y Tailwind CSS.
- Crea componentes reutilizables.
- Organiza el código en archivos y componentes independientes.
- Mantén una estructura limpia y fácil de modificar.
- Prioriza accesibilidad, rendimiento y diseño responsive.
- No inventes proyectos, experiencia laboral, certificaciones ni estadísticas.
- Utiliza contenido provisional únicamente donde todavía falte información.
